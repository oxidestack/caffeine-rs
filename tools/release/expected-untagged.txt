## [0.1.0] - YYYY-MM-DD

### Action required

- `strict_mode` is no longer read. A configuration that sets it sets `strict` to the same value instead. (ff96db8)

### Features

- Input may come from any `std::io::Read`. (d51965b)
- The `trim` option drops trailing whitespace from the output. (cache, f41e7f1)

### Bug fixes

- An error raised in a nested call names the position of the call, so a caller finds it. (f34e1f5)
- Input that is not UTF-8 returns an error instead of a panic. (5d0c6fb)
- An error names the line of the input, as the Java library does. (2efe6d5)

### Performance

- An input used twice is parsed once, so using it again is faster. (45b5df6)

### Other changes

- The README lists every option with its default. (deb40d4)
